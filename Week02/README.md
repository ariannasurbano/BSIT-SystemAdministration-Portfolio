## 📌 Project Overview

This project focuses on planning the IT infrastructure of ABC Startup Solutions, a newly established software development company with 20 employees. The project involves designing the company’s basic IT infrastructure before purchasing and deploying hardware, software, servers, and networking equipment.

The project demonstrates the importance of proper infrastructure planning, documentation, network design, security, backup, and future expansion.

## 👨‍💻 System Administration Roles

The project researched four important system administration roles:

### Helpdesk Technician

Provides first-level technical support, troubleshoots hardware and software problems, manages support tickets, and assists end users.

### Network Administrator

Manages routers, switches, firewalls, wireless networks, IP addressing, network security, and network performance.

### Linux System Administrator

Installs and maintains Linux servers, manages permissions, system updates, security configurations, storage, and server applications.

### Cloud Administrator

Manages cloud computing resources, identity and access management, cloud backups, monitoring, security, and cloud costs.

These professionals work together to maintain system availability, network connectivity, security, data integrity, and business continuity.

## 🔐 Infrastructure Recommendations

The project recommends a reliable enterprise fiber Internet connection with a secondary Internet connection for failover.

For the server infrastructure, an enterprise rackmount server with ECC memory and RAID storage is recommended.

A **3-2-1 backup strategy** is also recommended using primary production data, local NAS storage, and an offsite backup.

Security recommendations include:

* Microsoft Defender for Endpoint
* Strong password requirements
* Multi-factor authentication (MFA)
* VPN security
* Automatic screen locking
* Firewall protection
* Regular backups

The infrastructure is also designed to allow future employee and network expansion.
